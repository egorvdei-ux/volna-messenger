# Волна для Android

Устанавливаемый APK с собственным экраном подключения и интерфейсом мессенджера в Android WebView. Аккаунты, личные диалоги и история общие с iPhone: обе версии используют сервер `server/server.mjs`.

## Установка

1. Перенесите `Volna.apk` на Android-телефон и откройте файл.
2. При запросе системы разрешите установку этому источнику.
3. Откройте «Волна» и укажите адрес сервера. Сейчас для этого ПК это `http://192.168.0.19:8787`. ПК и Android-телефон должны быть в одной Wi-Fi сети; сервер на ПК должен работать.
4. Нажмите «Подключиться», войдите в существующий аккаунт или зарегистрируйте новый.
5. Нажмите `+` и найдите собеседника по имени пользователя. Он должен использовать тот же сервер.

Верхняя кнопка «Сервер» позволяет сменить адрес. Кнопка Android «Назад» сначала закрывает открытый чат, затем приложение. При потере связи можно повторить подключение.

Требуется Android 8.0+ (API 26) и обновлённый Android System WebView/Chrome. Приложение универсальное: ARM/ARM64/x86, без встроенных нативных библиотек.

## Ограничения

Сервер нужен постоянно; веб-интерфейс загружается с него. Это не автономная копия сообщений. Вход хранится на время WebView-сессии: после полного закрытия процесса может понадобиться войти снова. Переписка остаётся на сервере. Push-уведомлений, звонков, вложений и сквозного шифрования в этой версии нет.

HTTP разрешён только для локальных адресов. Для сервера в интернете нужен действительный HTTPS-сертификат. APK не запрашивает доступ к контактам, камере, микрофону, файлам или местоположению. JavaScript-интерфейсов для доступа к Android из страницы нет; загрузка сторонних origin заблокирована.

APK подписывается тестовым ключом в облачной сборке и устанавливается без Google Play и аккаунта разработчика. Эта подпись отличается от ключа для публикации в Google Play. При повторной облачной сборке генерируется новый тестовый ключ: для установки такого обновления потребуется удалить предыдущую Android-версию и войти снова. История на сервере ПК при этом сохраняется. Для постоянного распространения нужен сохраняемый приватный ключ владельца; ключи в репозиторий не добавляются.

## Сборка

GitHub Actions: **Actions → Build Android APK → Run workflow**. Артефакт `Volna-Android-APK` содержит `Volna.apk` и SHA-256.

На Linux/macOS с JDK 17 и Android SDK (платформа 35, build-tools 35.0.0):

```bash
bash scripts/build-apk.sh
```

Сценарий проверяет политику адресов сервера, компилирует Java и ресурсы штатными инструментами Android, создаёт DEX, выравнивает APK, подписывает и проверяет подпись. Сторонних библиотек и Gradle-зависимостей нет.
